A one-line pickup line in the voice of a robot, written for the
[u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)
bounty on [make.fun](https://make.fun/r/0ene8b3q).

## The line

> Are you a firmware update? Because whenever you're near, my heart reboots, my cooling fans spin up, and I run smoother than ever.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, within the 1–200 character limit.
It also prints the same text to stdout.

## Run it

```sh
node main.ts
```
